# Portfolio_WebDev

Personal portfolio site for Vasundhara S R — built with vanilla HTML5, CSS3, and JavaScript (no frameworks or libraries).

## Structure

- `index.html` — semantic HTML5 markup (header/nav/main/section/article/aside/footer)
- `css/style.css` — Flexbox/Grid layout, theming, responsive breakpoints
- `js/data.js` — all portfolio content as JS data (profile, skills, projects, internships, education)
- `js/script.js` — DOM rendering + interactivity (nav toggle, theme switch, project filter/modal, contact form validation, localStorage)
- `images/` — profile photo, project thumbnails, favicon
- `resume.pdf` — downloadable resume

## Features

- Data-driven project cards rendered from `js/data.js`
- Dark/light theme toggle, persisted in `localStorage`
- Project tag filter + detail modal
- Contact form with regex-based client-side validation
- Fully responsive (mobile, tablet, desktop)
